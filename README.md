A one-line weather forecast for Bumbershoot Falls, a city that does not exist — drizzle, frogs, and the 7:42 running on time for once. A tiny Node program writes the forecast to /output/entry.txt for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty.

## Run it

```sh
node main.ts
```
